# 휴가 기록 (vacation)

직원이 휴가를 직접 입력하고, 관리자는 월별 현황을 보고 엑셀로 받는 사내 휴가 기록 시스템입니다.

## 기능

보유 연차나 잔여 일수는 다루지 않습니다. 직원마다 보유 연차가 달라 일원화하기 어렵기 때문에, **언제 며칠 썼고 올해 누적 몇 일인지** 만 집계합니다.

**직원** (휴대폰에서 카톡 링크로 접속)
- 이름 + 전화번호로 로그인
- 휴가 등록: 연차, 오전/오후 반차, 병가, 경조사, 기타. 주말과 공휴일은 자동 제외
- 올해 연차 누적 사용일, 이번 달 사용일, 기타 휴가 일수 확인
- 월말 "입력 완료" 버튼. 누르면 그 달은 잠깁니다

**관리자** (`/admin`)
- 월별 현황: 직원별 이번 달·올해 휴가 등록 건수와 일수, 이번 달 사용 내역, 최근 입력·수정 시각, 입력 완료 여부
- 최근 입력순 정렬로 누가 최근에 입력했는지 한눈에 확인
- 미입력자 명단 복사, 카톡 안내문 복사
- 엑셀 다운로드: 월 현황, 월 상세 내역, 연간 월별 표
- 직원 관리: 엑셀 붙여넣기로 일괄 등록, 퇴사 처리
- 대리 등록/삭제, 입력 완료 취소, 공휴일 관리

## 처음 설정하기

배포는 **Cloudflare Workers + Supabase 무료 요금제** 조합으로 합니다. 결정 이유와 상세 절차는 [DEPLOY.md](DEPLOY.md) 에 있습니다.

### 1. 데이터베이스와 배포
1. Supabase 프로젝트를 만들고 `db/schema.sql`, `db/holidays.sql` 을 실행합니다.
2. Cloudflare Hyperdrive 를 만들고 `wrangler.jsonc` 에 id 를 넣은 뒤 `npm run deploy` 로 배포합니다.
3. `SESSION_SECRET`, `ADMIN_PASSWORD` 비밀값을 넣습니다.
4. GitHub 저장소에 Cloudflare 시크릿과 `VACATION_URL` 변수를 넣으면 자동 배포와 Supabase 정지 방지가 켜집니다.

### 2. 관리자 로그인
`https://배포주소/admin` 에서 관리자 비밀번호로 로그인합니다.

### 3. 직원 등록과 안내
1. **직원** 메뉴에서 엑셀의 이름, 전화번호, 부서 열을 복사해 붙여넣습니다.
2. **월별 현황 → 카톡 안내문 복사** 로 직원 단톡방에 링크를 보냅니다.
3. 기존 엑셀의 올해 사용 내역은 **휴가 기록 → 관리자 대리 등록** 으로 옮깁니다.

## 매달 운영
1. 직원은 휴가를 쓸 때마다, 또는 월말에 몰아서 입력하고 **입력 완료**를 누릅니다.
2. 관리자는 월말에 **월별 현황** 에서 미입력자를 확인하고 **명단 복사** 로 카톡을 보냅니다.
3. 모두 완료되면 **월 현황 엑셀** 을 내려받아 보고합니다.
4. 새해가 되면 **공휴일** 을 확인합니다. 누적 일수는 1월 1일부터 자동으로 새로 셉니다.

## 로컬 개발
```bash
cp .env.example .env.local   # 값 채우기
npm install
npm run db:init              # DATABASE_URL 의 DB 에 스키마/공휴일 생성
npm run dev                  # Node 로 실행
npm test                     # 휴가 일수 계산 단위 테스트
npm run preview              # Cloudflare 와 같은 런타임으로 실행 (DEPLOY.md 참고)
```

## 업데이트할 때
- `db/schema.sql` 은 여러 번 실행해도 안전합니다. 새 버전을 받으면 Supabase SQL Editor 에서 한 번 더 실행해 새 열을 추가하세요.

## 알아둘 점
- 이름 + 전화번호 로그인은 편하지만, 동료의 번호를 아는 사람은 그 사람으로 로그인할 수 있습니다. 민감한 사유는 메모에 적지 않도록 안내하세요. 필요해지면 카카오 로그인이나 개인 PIN 을 추가할 수 있습니다.
- 공휴일 기본값은 2026~2027년입니다. 임시공휴일 발표 시 관리자 화면에서 추가하세요. 이미 등록된 휴가의 일수는 자동으로 다시 계산되지 않습니다.
- 연차 누적에는 연차와 반차만 들어가고, 병가·경조사·기타는 기타 휴가로 따로 셉니다. 병가나 경조사도 연차로 세려면 `src/lib/leave.js` 의 `deduct` 값을 바꾸면 됩니다.
- 올해 누적에는 오늘 이후로 미리 등록한 예정 휴가도 포함됩니다.
