# 휴가 기록 (vacation)

직원이 휴가를 직접 입력하고, 관리자는 월별 현황을 보고 엑셀로 받는 사내 휴가 기록 시스템입니다.

## 기능

**직원** (휴대폰에서 카톡 링크로 접속)
- 이름 + 전화번호로 로그인
- 휴가 등록: 연차, 오전/오후 반차, 병가, 경조사, 기타. 주말과 공휴일은 자동 제외
- 올해 부여 / 사용·예정 / 잔여 연차 확인
- 월말 "입력 완료" 버튼. 누르면 그 달은 잠깁니다

**관리자** (`/admin`)
- 월별 현황: 직원별 이번 달 사용, 올해 누적, 잔여, 입력 완료 여부
- 미입력자 명단 복사, 카톡 안내문 복사
- 엑셀 다운로드: 월 현황, 월 상세 내역, 연간 월별 표
- 직원 관리: 엑셀 붙여넣기로 일괄 등록, 연도별 부여 일수, 퇴사 처리
- 대리 등록/삭제, 입력 완료 취소, 공휴일 관리

## 처음 설정하기

### 1. 데이터베이스 (Supabase 무료 요금제)
1. https://supabase.com 에서 새 프로젝트를 만듭니다. 지역은 Seoul(ap-northeast-2)을 고릅니다.
2. 왼쪽 **SQL Editor** 에서 `db/schema.sql` 내용을 붙여넣고 실행합니다.
3. 이어서 `db/holidays.sql` 도 실행합니다.
4. **Project Settings → Database → Connection string → Transaction pooler** 주소를 복사해 둡니다. `[YOUR-PASSWORD]` 부분은 프로젝트 비밀번호로 바꿉니다.

### 2. Vercel 배포
1. Vercel 에서 **Add New Project → `itnad/ai` 저장소** 를 고르고 **Root Directory 를 `vacation`** 으로 지정합니다.
2. Environment Variables 에 세 값을 넣습니다.

| 이름 | 값 |
|---|---|
| `DATABASE_URL` | 1번에서 복사한 접속 주소 |
| `SESSION_SECRET` | 32자 이상 무작위 문자열 (예: `openssl rand -base64 32` 결과) |
| `ADMIN_PASSWORD` | 관리자 비밀번호 |

3. 배포 후 `https://배포주소/admin` 에서 관리자로 로그인합니다.
4. AI 이슈 워크플로우로 자동 배포하려면 GitHub Secrets 에 `VERCEL_PROJECT_ID_VACATION` 을 추가합니다.

### 3. 직원 등록과 안내
1. **직원·연차** 메뉴에서 엑셀의 이름, 전화번호, 부서, 부여일수 열을 복사해 붙여넣습니다.
2. **월별 현황 → 카톡 안내문 복사** 로 직원 단톡방에 링크를 보냅니다.
3. 기존 엑셀의 올해 사용 내역은 **휴가 기록 → 관리자 대리 등록** 으로 옮깁니다.

## 매달 운영
1. 직원은 휴가를 쓸 때마다, 또는 월말에 몰아서 입력하고 **입력 완료**를 누릅니다.
2. 관리자는 월말에 **월별 현황** 에서 미입력자를 확인하고 **명단 복사** 로 카톡을 보냅니다.
3. 모두 완료되면 **월 현황 엑셀** 을 내려받아 보고합니다.
4. 새해가 되면 **직원·연차** 에서 해당 연도 부여 일수를 설정하고, **공휴일** 을 확인합니다.

## 로컬 개발
```bash
cp .env.example .env.local   # 값 채우기
npm install
npm run db:init              # DATABASE_URL 의 DB 에 스키마/공휴일 생성
npm run dev
npm test                     # 휴가 일수 계산 단위 테스트
```

## 알아둘 점
- 이름 + 전화번호 로그인은 편하지만, 동료의 번호를 아는 사람은 그 사람으로 로그인할 수 있습니다. 민감한 사유는 메모에 적지 않도록 안내하세요. 필요해지면 카카오 로그인이나 개인 PIN 을 추가할 수 있습니다.
- 공휴일 기본값은 2026~2027년입니다. 임시공휴일 발표 시 관리자 화면에서 추가하세요. 이미 등록된 휴가의 일수는 자동으로 다시 계산되지 않습니다.
- 회사 규정상 병가나 경조사를 연차에서 차감한다면 `src/lib/leave.js` 의 `deduct` 값을 바꾸면 됩니다.
