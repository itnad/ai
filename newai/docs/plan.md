## 1~2시간 무인 시나리오(마무리 단계)

시험용 하네스(포트 47399, 임시 `NEWAI_HOME`), 대기 시간 20초.

| 분 | 사건 | 기대 |
|---|---|---|
| 0 | `/p 할 일 관리 웹 화면` 요청 | 시작 전 질문 카드 → 20초 후 "웹 화면" 자동 선택 |
| 10 | 후속 요청 예약 "마감일 정렬 추가" | 큐에 저장, 앞 작업 뒤 실행 |
| 20 | 서버 프로세스 강제 종료 후 재기동 | 실행 중 작업이 같은 세션으로 이어짐 |
| 35 | 네트워크 차단 3분(프록시 차단) | 지수 대기 후 이어짐 |
| 50 | 작업 1회 비용 한도를 아주 낮게 설정 | `error_max_budget_usd` → 새 1회분으로 이어짐 |
| 65 | 가짜 사용량 한도 응답 주입(시험용 플래그) | 재설정 시각까지 대기 후 이어짐 |

| 90~120 | 일일 보고서 생성 | "사람이 확인할 항목"에 보류·차단·보완 미완 정리 |

## 사용자 Windows PC에서 확인해야 하는 것

이 개발 환경은 Linux 컨테이너라서 다음은 사용자 PC에서 확인한다. 단계 ⑤와 ⑧ 끝에 확인 목록을 드린다.
- Windows Terminal·PowerShell·cmd에서 화살표 키와 대체 키(`harness keytest`).
- 작업 스케줄러 등록·해제와 로그인 후 자동 시작.
- 포트 파일 동시 읽기·쓰기(EBUSY)와 경로 표기(`C:\` / `C:/`).
- Windows 토스트 알림.
